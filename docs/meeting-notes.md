### 二、项目主题确认

本小组项目名称为 **Gatherly**。

Gatherly 是一个面向小众兴趣爱好者的线下活动聚合与同好匹配平台，主要解决用户“想玩但找不到同好、不知道去哪玩”的问题。

项目围绕以下核心场景展开：

- 复古相机 / 胶片摄影
- 城市骑行
- 手冲咖啡
- 独立出版
- 摄影展 / 周末活动
- 小众兴趣临时约伴

平台希望通过“活动聚合 + 同好圈 + 信任机制”的方式，为用户提供真实、轻量、低打扰的兴趣活动体验。

---

### 三、项目核心功能讨论

经过讨论，本项目初步确定以下核心功能：

| 模块 | 功能说明 |
|---|---|
| 活动版块 | 首页活动流、活动详情、活动发布、活动报名、人数上限、满员提示 |
| 同好圈 | 按兴趣标签建立圈子，用户可浏览圈子、发布经验分享或临时约伴 |
| 用户系统 | 用户注册、登录、退出、个人主页、兴趣标签 |
| 信任机制 | 活动评分、履约评分、商家认证、低评分限制发起活动 |
| 文档与测试 | README、Product Backlog、会议记录、功能截图、演示素材 |

### 七、GitHub 协作规则

本次会议确定 GitHub 协作流程如下：

1. 所有成员不要直接在 main 分支开发；
2. 每个任务对应一个 GitHub Issue；
3. 成员开发前从 main 分支创建自己的 feature 分支；
4. 开发完成后提交 Pull Request；
5. 组长检查代码后再合并到 main；
6. GitHub Project 看板用于同步任务状态；
7. 每周保留 Issues、Milestones、Projects、Pull Requests 等过程截图。
