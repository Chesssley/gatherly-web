# 注册功能说明

本文档记录 Gatherly Web 注册功能的实现范围和验证方式。安装运行步骤见根目录 `README.md`。

## 功能概述

已实现用户故事：作为游客，我想注册一个 Gatherly 账号，以便后续使用报名、发帖和个人主页等功能。

## 验收标准

| 验收标准 | 状态 | 说明 |
|---|---|---|
| 用户可以进入注册页面 | 已完成 | 访问 `/register` |
| 注册表单包含用户名、邮箱、密码和确认密码 | 已完成 | 使用 Flask-WTF 表单 |
| 用户可以提交注册信息 | 已完成 | `POST /register` |
| 注册成功后用户信息能够保存 | 已完成 | 保存到 SQLite，密码哈希存储 |
| 注册失败时有基本错误提示 | 已完成 | 表单验证和 Flash 消息 |

## 涉及文件

| 文件 | 说明 |
|---|---|
| `app/forms.py` | 定义 `RegistrationForm`，包含字段和校验规则 |
| `app/routes/auth.py` | 处理注册、登录、退出相关路由 |
| `app/templates/register.html` | 注册页面模板 |
| `app/templates/base.html` | Flash 消息展示区域 |
| `app/static/css/style.css` | 表单和消息提示样式 |
| `app/models.py` | `User` 模型 |

## 技术要点

- 使用 Flask-WTF 处理注册表单。
- 使用 `werkzeug.security.generate_password_hash` 存储密码哈希。
- 使用 SQLAlchemy ORM 写入用户数据。
- 服务端校验用户名、邮箱、密码长度和确认密码一致性。
- 使用 Flash 消息展示成功或失败结果。

## 测试用例

### 成功注册

1. 访问 `/register`。
2. 输入用户名 `testuser`、邮箱 `test@example.com`、密码 `123456`、确认密码 `123456`。
3. 点击注册。
4. 预期跳转到登录页，并显示注册成功提示。

### 验证失败

| 场景 | 输入 | 预期 |
|---|---|---|
| 密码不一致 | 密码 `123456`，确认密码 `123457` | 显示密码不一致提示 |
| 密码太短 | 密码 `123` | 显示密码长度提示 |
| 邮箱格式错误 | 邮箱 `test` | 显示邮箱格式提示 |
| 用户名重复 | 使用已存在用户名 | 显示用户名已注册提示 |
| 邮箱重复 | 使用已存在邮箱 | 显示邮箱已注册提示 |

## 后续优化

- 邮箱验证。
- 密码重置。
- 个人资料编辑。
- 注册后自动登录或更明确的新手引导。
