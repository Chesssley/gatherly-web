# Gatherly Web / 聚场项目计划

## 项目定位

Gatherly Web / 聚场是一个面向小众兴趣爱好者的线下活动聚合与同好匹配网站。

## 第一阶段目标

- 搭建静态页面文件结构。
- 完成首页、活动列表、活动详情、发布活动、圈子、个人主页、登录、关于页面。
- 使用统一的 HTML、CSS 和 JavaScript 组织方式。
- 准备项目文档，方便新手组员协作。

## 后续方向

- 补充活动筛选和搜索交互。
- 完善活动详情和报名流程。
- 设计用户兴趣标签与同好匹配展示。
- 根据课程要求逐步完善页面内容和交互。
