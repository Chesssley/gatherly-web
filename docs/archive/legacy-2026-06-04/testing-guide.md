# 测试与验收指南

当前仓库没有独立自动化测试套件，因此本指南以可执行检查和手动验收为主。所有业务代码修改完成后，都应至少执行 Python 编译检查。

## 必跑检查

Windows PowerShell：

```powershell
python -m compileall app run.py
```

macOS / Linux：

```bash
python -m compileall app run.py
```

该命令会检查 Python 文件是否存在语法错误。它不会替代功能测试。

## 启动检查

```bash
python run.py
```

打开：

```text
http://127.0.0.1:5000
```

确认首页可以加载，没有 Flask traceback。

## 文档检查

文档变更后检查：

```bash
git status
git diff -- README.md docs/
```

手动确认：

- README 中的 `docs/` 链接存在。
- `docs/` 内部相对链接存在。
- ER 图文件路径为 `docs/er-diagram.mmd`。
- 中文文档没有指向已删除或旧路径。
- README 为英文。
- README 中没有中文正文残留。

## 敏感信息检查

提交前确认没有以下内容：

- 真实 API Key。
- 真实邮箱验证码。
- 真实密码。
- `.env`。
- `instance/*.db`。
- `venv/` 或 `.venv/`。
- `__pycache__/`。
- 用户真实上传文件。

建议命令：

Windows PowerShell：

```powershell
git status --short
rg "API_KEY|PASSWORD|SECRET|验证码|verification code|BEGIN PRIVATE KEY" README.md docs app
```

macOS / Linux：

```bash
git status --short
rg "API_KEY|PASSWORD|SECRET|验证码|verification code|BEGIN PRIVATE KEY" README.md docs app
```

如果命令命中的是示例变量名，需要人工确认没有真实值。

## 手动验收清单

### 账号与认证

- 注册页面可打开。
- 本地 console 模式下可以发送验证码并完成注册。
- 可以登录和登出。
- 找回密码页面可打开。
- 账号设置页可打开。
- 修改邮箱和修改密码需要验证码。

### 活动

- 首页活动流可打开。
- 搜索建议和搜索结果可用。
- 活动详情页可打开。
- 登录用户可以进入活动发布页。
- 活动发布表单校验必填项。
- 活动报名能创建记录。
- 已报名用户不能重复报名。
- 满员、过期或非开放活动不能报名。
- 非组织者可在活动开始前取消报名。
- 收藏活动可切换状态。
- 活动评论可提交。

### 同好圈

- 同好圈列表可打开。
- 同好圈详情可打开。
- 登录用户可加入和退出圈子。
- 登录用户可创建圈子。
- 圈内可发帖。
- 帖子可评论和回复。
- 帖子和评论互动可记录。
- 圈主或管理员操作入口可用。

### 私信与通知

- 私信列表可打开。
- 用户之间可发送文字消息。
- 图片消息大小和格式校验有效。
- 未读计数更新。
- 会话隐藏或删除不影响另一方数据。
- 通知列表可打开。
- 通知可标记已读。
- 全部已读可执行。

### 个人主页

- 当前用户主页可打开。
- 其他用户主页可打开。
- 编辑资料可保存。
- 头像上传格式校验有效。
- 关注和取消关注可执行。
- 粉丝和关注列表可打开。
- 附近的人功能可开关。

### 评分与信任

- 已结束活动后参与者互评入口可用。
- 不能评价自己。
- 不能评价未参与者。
- 评分范围必须为 1 到 5。
- 提交后信任分日志有记录。

### 管理员

- 非管理员访问后台会被拦截。
- 管理员 dashboard 可打开。
- 用户管理可搜索、封禁、解封。
- 活动管理可修改状态和加精。
- 圈子、帖子、评论管理可执行状态修改。
- 商家认证审核可保存结果。
- 管理日志有记录。

## PR 验收建议

PR 描述至少包含：

- 关联 Issue。
- 修改摘要。
- 执行过的命令。
- 手动检查页面。
- UI 改动截图。
- 是否影响数据库模型、路由或模板。
