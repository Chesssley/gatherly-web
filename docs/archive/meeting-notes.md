## Sprint 1 摘要

Sprint 1 的目标是完成 Gatherly Web 的项目基础框架和核心页面雏形，包括 Flask 应用结构、首页活动流、活动详情页、用户注册登录起步、Product Backlog、会议记录和协作规范。

本阶段重点结论：

- 项目定位为小众兴趣线下活动聚合与同好匹配平台。
- 技术栈固定为 Flask + Jinja2 + HTML/CSS/原生 JavaScript。
- 团队通过 GitHub Issues、Milestones、Projects、Branches 和 Pull Requests 协作。
- 所有成员不直接在 `main` 分支开发。
- 每个任务对应一个 Issue 和一个独立开发分支。
- 文档、截图和会议记录需要随 Sprint 推进持续补充。

## 后续维护方式

- 每次 Sprint 会议新增一个独立 Markdown 文件。
- 文件命名建议使用 `sprintN-meeting.md` 或 `YYYY-MM-DD-topic.md`。
- 总览文件只放索引和摘要，不重复粘贴完整会议纪要。
- 会议中的任务变化应同步更新 `docs/product-backlog.md` 和 GitHub Project。
