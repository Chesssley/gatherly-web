## 项目主题确认

项目名称为 Gatherly Web。项目面向小众兴趣爱好者，解决用户想参加线下活动但难以找到本地活动和同好人群的问题。

核心场景包括：

- 胶片摄影、复古相机、摄影展。
- 城市骑行、徒步、轻户外。
- 手冲咖啡、独立出版、书店探访。
- 桌游、剧本围读、观影交流。
- 小众兴趣临时约伴。

## 核心功能讨论

| 模块 | 功能说明 |
|---|---|
| 活动版块 | 首页活动流、活动详情、活动发布、活动报名、人数上限、满员提示 |
| 同好圈 | 按兴趣标签建立圈子，用户可浏览圈子、发布经验分享或临时约伴 |

| 信任机制 | 活动评分、履约评分、商家认证、低评分限制发起活动 |
| 文档与测试 | README、Product Backlog、会议记录、功能截图、演示材料 |

## GitHub 协作规则

1. 所有成员不要直接在 `main` 分支开发。
2. 每个任务对应一个 GitHub Issue。
3. 成员开发前从 `main` 分支创建自己的 feature 分支。
4. 开发完成后提交 Pull Request。
5. 组长检查代码后再合并到 `main`。
6. GitHub Project 看板用于同步任务状态。
7. 每周保留 Issues、Milestones、Projects、Pull Requests 等过程截图。

## Project 看板状态

| 看板列 | 含义 |
|---|---|
| Product Backlog | 后续要做但当前 Sprint 不做的任务 |
| Sprint Backlog | 当前 Sprint 计划完成的任务 |
| In Progress | 正在开发的任务 |
| Code Review | 已提交 PR，等待审查 |
| Done | 已完成 |
