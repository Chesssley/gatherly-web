# Gatherly Product Backlog

本文件记录 Gatherly 项目的产品待办列表。Product Backlog 包含项目从启动到最终交付所需完成的用户故事、技术任务和文档任务。

## 一、优先级说明

| 优先级 | 含义 |
|---|---|
| P0 | 必须完成，没有该功能项目无法形成基本闭环 |
| P1 | 重要功能，能够体现项目特色 |
| P2 | 加分功能，时间允许时完成 |

## 二、故事点说明

| 故事点 | 难度说明 |
|---|---|
| 1 | 极简单，少量修改 |
| 2 | 简单，静态页面或文档任务 |
| 3 | 中等，需要页面和数据展示 |
| 5 | 较复杂，涉及表单、数据库或登录状态 |
| 8 | 复杂，涉及多个模块联动 |
