# 项目概览

## 项目定位

Gatherly Web「聚场」是一个基于 Flask 的本地小众兴趣线下活动聚合与同好匹配平台。项目关注“想参加线下活动，但不知道哪里能找到合适活动和可靠同伴”的场景，通过活动发现、报名、同好圈、轻社交互动和信任评分，帮助用户围绕真实兴趣建立线下连接。

## 核心场景

- 用户浏览本地或主题化的小众兴趣活动。
- 用户查看活动详情，判断时间、地点、费用、名额和准备事项是否合适。
- 用户报名活动、取消报名、收藏活动，并在活动结束后评价参与者。
- 用户加入同好圈，在圈内发帖、评论、回复和互动。
- 用户通过个人主页、关注关系、私信和通知维持轻量社交连接。
- 管理员处理用户、活动、圈子、帖子、评论和商家认证等后台事务。

## 目标用户

- 想发现本地小众兴趣活动的普通用户。
- 想组织线下兴趣活动的活动发起者。
- 希望围绕共同兴趣持续交流的同好圈成员。
- 需要维护内容质量、用户状态和认证流程的管理员。
- 课程项目评审者和协作者。

## 核心价值

- 用清晰的活动信息降低线下参与门槛。
- 用兴趣圈承接活动前后的持续交流。
- 用报名记录、互评、信任分和后台管理提升平台秩序。
- 用 GitHub Issues、分支、PR 和文档沉淀可追踪的团队协作过程。

## 当前技术边界

项目以当前仓库代码为准，技术栈保持轻量：

- 后端：Flask
- 数据层：Flask-SQLAlchemy + SQLite
- 表单：Flask-WTF、WTForms、email-validator
- 前端：Jinja2 模板、HTML、CSS、原生 JavaScript
- 邮件：本地 console、Brevo Transactional Email API、SMTP

当前代码没有使用 React、Vue、Bootstrap、Docker、PDM、Poetry 或独立前端构建工具。后续如果引入新技术，应先创建对应 Issue 并说明影响范围。

## 当前完成范围

以当前代码为准，项目已经具备：

- 账号注册、登录、登出、邮箱验证码、找回密码、账号设置和注销。
- 首页活动流、活动搜索、活动详情、活动发布、报名、取消报名、收藏、评论和活动状态处理。
- 同好圈列表、创建、加入、退出、私密访问申请、帖子、评论、回复、图片和互动。
- 用户主页、关注关系、附近的人、资料可见性设置。
- 私信会话、未读状态、图片消息、会话隐藏/删除。
- 通知列表、已读、全部已读。
- 评分与信任机制，包括活动评分、参与者互评和信任分日志。
- 管理员后台，包括用户、活动、圈子、帖子、评论、日志和商家认证管理。
