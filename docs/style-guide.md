# 页面风格规范

## 总体风格

Gatherly Web / 聚场的页面风格应保持温和、清晰、可信，适合展示小众兴趣线下活动。页面不要过度花哨，优先保证信息好读、按钮好找、路径清楚。

## 颜色

- 背景色使用柔和浅色，避免纯白大面积刺眼。
- 主色使用绿色系，体现线下连接、社区和友好感。
- 强调色可使用暖橙色，用于少量提示或视觉重点。
- 同一页面不要随意增加新的主色。

## 字体与文字

- 全站使用统一字体设置，优先使用 `Microsoft YaHei`、`PingFang SC`、Arial。
- 标题要简洁，正文要说明具体信息。
- 页面中的按钮文案使用动词，例如“浏览活动”“发布活动”“报名参加”。

## 布局

- 页面内容使用统一 `.container` 控制宽度。
- 页面主要区块使用 `.section` 保持上下间距。
- 卡片、表单、信息面板使用统一圆角和边框。
- 移动端需要保证内容自然换行，不出现横向滚动。

## 组件

- 按钮统一使用 `.button`。
- 活动卡片统一使用 `.activity-card` 和 `.card-body`。
- 标签统一使用 `.tag`。
- 表单统一使用 `.form-card`。

## 协作要求

- 新增页面必须引用四个公共 CSS 文件。
- 首页 CSS 路径使用 `assets/css/xxx.css`。
- `pages` 目录下页面 CSS 路径使用 `../assets/css/xxx.css`。
- 不要在 HTML 中写大量内联样式。
- 修改公共样式前先确认是否影响多个页面。
