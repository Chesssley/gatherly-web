# 样式规范

最后更新时间：2026-06-04

本文根据当前 `app/static/css/style.css` 和模板整理。项目使用自定义 CSS，不引入 Bootstrap 或其他 UI 框架。

## 设计方向

- 真实、轻量、移动端优先。
- 信息层级清楚，卡片内容可快速扫描。
- 活动报名、发布、加入、发帖等行动按钮要明确。
- 图片展示真实内容，不做过度滤镜。
- 页面整体保持克制，不做复杂动效或重型视觉装饰。

## 颜色规范

当前 CSS 根变量：

| 变量 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#f7f4ef` | 页面背景 |
| `--color-surface` | `#ffffff` | 卡片和表单表面 |
| `--color-text` | `#222222` | 主要文本 |
| `--color-muted` | `#6b665f` | 次级文本 |
| `--color-primary` | `#2f6f63` | 主按钮、强调色、品牌色 |
| `--color-primary-dark` | `#24564d` | hover、深色强调 |
| `--color-border` | `#ded8cf` | 边框 |

常见辅助色：

| 颜色 | 用途 |
|---|---|
| `#e8f0ed` | 浅绿色背景、次级按钮 hover |
| `#e6f3ef` | 标签背景 |
| `#e63946` | 错误或危险状态 |
| `#fca311` | 警告或过期状态 |
| `#52c41a` | 成功状态 |

## 按钮

- 主按钮使用绿色背景、白色文字、8px 圆角。
- 次级按钮使用透明或白底，绿色文字和边框。
- 禁用按钮使用灰色背景，并设置 `cursor: not-allowed`。
- 危险操作按钮要有确认提示，尤其是删除、封禁、注销。
- 移动端按钮应有足够点击面积。

## 活动卡片

活动卡片通常包含：

- 活动图片；
- 活动标题；
- 日期或时间；
- 城市 / 地点；
- 标签；
- 人数或热度；
- 进入详情的链接。

样式要求：

- 卡片间距统一。
- 图片比例稳定，避免拉伸。
- 标题不要被按钮或标签遮挡。
- hover 可以使用轻微阴影或缩放，但移动端不依赖 hover。

## 圈子卡片

圈子卡片通常包含：

- 封面图；
- 圈子名称；
- 标签；
- 简介；
- 成员数或活跃信息；
- 加入或查看入口。

样式要求：

- 与活动卡片风格一致，但允许更强调社区属性。
- 系统圈子、官方圈子或置顶圈子要通过清晰标签区分。
- 不要用纯文字堆叠替代封面或状态信息。

## 标签 Chip

标签用于兴趣分类、筛选和状态提示。

要求：

- 使用圆角胶囊或轻量矩形。
- 背景色保持浅色，文字使用主色或深色。
- 当前选中标签需要明显区分。
- 标签文本要短，不要放长句。

## 表单

表单用于注册、登录、活动发布、创建圈子、发帖、账号设置和后台操作。

要求：

- label、输入框、提示和按钮垂直对齐。
- 输入框使用清楚边框和 focus 状态。
- 必填字段应在交互或错误提示中明确。
- 错误提示使用红色或明显文本，不只依赖颜色。
- 图片上传按钮文案清楚，如“选择图片”。

## 导航栏

当前导航包含品牌、搜索、活动、圈子、用户状态、消息、通知和管理员入口等内容。

要求：

- 登录和未登录状态入口不同。
- 移动端搜索和操作入口不能挤压品牌。
- 管理员入口只对管理员可见。
- 导航栏链接文字要短，避免折行混乱。

## 移动端响应式

当前 CSS 包含多个断点，例如 `1180px`、`980px`、`860px`、`768px`、`720px`、`640px`、`560px`、`420px`。

要求：

- 移动端优先保证内容可读和按钮可点。
- 卡片列表在小屏下改为单列。
- 表单宽度不超过屏幕。
- 导航、搜索、筛选控件在窄屏下可折行或隐藏次要项。
- 不要使用固定大宽度导致横向滚动。

## 图片命名

| 类型 | 建议路径 | 命名示例 |
|---|---|---|
| 活动图片 | `app/static/images/activities/` | `city-photo-walk.webp` |
| 圈子封面 | `app/static/images/circle_covers/` | `coffee.webp` |
| 圈子图标 | `app/static/images/circles/` | `circle-camera.svg` |
| 文档截图 | `docs/screenshots/` | `home-activity-feed.png` |

命名规则：

- 使用英文小写。
- 单词之间用 `-`。
- 不使用空格和中文文件名。
- 上传生成的文件可以保留哈希名，但文档截图建议使用可读名称。

## CSS 书写规范

- 优先复用已有变量和类名。
- 新样式尽量放在相关页面已有区域附近。
- 避免大范围重写全局选择器。
- 不要把临时调试样式提交到仓库。
- 不要引入 Bootstrap 或复制大段外部 UI 框架 CSS。
- 修改 `style.css` 后至少检查首页、活动详情、圈子详情、登录注册和移动端宽度。
