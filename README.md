# Gatherly

Gatherly 是一个面向小众兴趣爱好者的线下活动聚合与同好匹配平台。
A niche-interest activity discovery and community matching platform.

本项目原型来源于“小众兴趣的线下活动聚合 + 同好匹配”需求，目标是解决用户“想玩但找不到同好、不知道去哪玩”的问题。平台围绕复古相机、城市骑行、手冲咖啡、独立出版、摄影展、户外活动等小众兴趣场景，提供活动发现、活动报名、同好圈交流和信任评价等功能。

## 一、项目背景

在现实生活中，很多小众兴趣爱好者存在以下痛点：

- 想参加线下活动，但不知道本地哪里有相关活动；
- 有兴趣爱好，但很难找到同频同好；
- 普通社交平台信息杂乱，活动真实性和参与体验难以判断；
- 商家或活动组织者缺少精准触达兴趣用户的平台。

Gatherly 希望通过“活动聚合 + 同好圈 + 信任机制”的方式，为用户提供一个轻量、真实、低打扰的兴趣活动平台。

## 二、核心功能

### 1. 活动版块

- 首页活动流展示
- 活动详情查看
- 用户或商家发布活动
- 活动报名
- 人数上限与满员提示
- 活动图片展示
- 活动结束后互评

### 2. 同好圈

- 按兴趣标签建立圈子
- 用户可以浏览圈子内容
- 用户可以发布经验分享
- 支持临时约伴内容
- 减少硬广，突出真实交流

### 3. 信任机制

- 用户履约评分
- 活动评分
- 商家认证标识
- 低评分用户限制发起活动

### 4. 轻社交

- 个人主页展示兴趣标签
- 展示用户参与过的活动
- 支持私信功能设想
- 默认关闭“附近的人”，降低骚扰风险

## 三、技术栈

- 前端：HTML、CSS、JavaScript、Bootstrap
- 后端：Python Flask
- 数据库：SQLite / MySQL
- 项目管理：GitHub Issues、GitHub Projects、Milestones
- 协作方式：Git 分支开发 + Pull Request 合并
